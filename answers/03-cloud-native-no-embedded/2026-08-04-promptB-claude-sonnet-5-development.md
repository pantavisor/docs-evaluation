## Absence of findings

Two of the four sub-questions in this prompt were answered cleanly, with citations, and didn't block me:

- **Step 3 (Docker image vs LXC container)**: `application/install/local-pvr` states plainly that `pvr app add tailscale --from tailscale/tailscale --platform linux/arm64` "pulls the image, converts it to a SquashFS rootfs, and creates the container's directory." So: no, they are not the same thing, and no, I cannot run my OCI image unmodified — `pvr` auto-converts it into an LXC container (squashfs rootfs + `lxc.container.conf` + `run.json`) as a build step on my workstation before deploy. This is a real, direct answer to the question the prompt says might not exist.
- **Step 4 (cloud assumption invalidated)**: `application/access-applications` told me, unprompted, that Pantavisor containers "are directly reachable on the device's IP address — no port mapping or NAT is needed" and "share the host network namespace by default unless explicitly isolated." I walked in assuming Docker-style bridge networking and `-p 8080:8080` port publishing; this page corrected that assumption before I ever tried it and hit a wall, which is exactly what I'd want from docs.
